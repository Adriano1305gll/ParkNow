# Park Now — AI-101 Capstone Prototype

Park Now is a parking-availability web application concept that displays available and occupied parking spaces on a visual lot map. This capstone version uses simulated occupancy updates unless connected to real sensors or an approved live data source.

## Run locally
```bash
npm install
npm run dev
```

## Suggested production stack
Next.js + React + Tailwind CSS + Vercel + Supabase.

## Required next steps for final submission
- Create a GitHub repository and commit incrementally (minimum 5 commits).
- Create a Supabase project and tables for parking lots, spaces, occupancy events, user tests, and assistant logs.
- Connect the UI to Supabase.
- Deploy at least twice to Vercel.
- Test with at least 5 external users and document evidence.
- Record a 5-minute final demo.
